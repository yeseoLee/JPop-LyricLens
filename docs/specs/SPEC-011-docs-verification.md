## 1. 목적
PRD 6장 산출물(요구사항 정의서·RAG 파이프라인 설계문서·검증 결과·README)을 저장소 안 문서로 갖춘다.

## 2. 범위
- 포함
  - `README.md`: 개요, 실행 방법(설치 → .env → 수집 → 색인 → 실행), 기능 목록(필수/심화 구분), 데이터 준비 절차, 출처와 이용 조건, 모델 변경 시 재색인 안내, 개발 흐름(AGENTS.md 링크)
  - `docs/rag_pipeline.md`: 컬렉션 3개 구조·메타데이터, 수집→청킹→색인 흐름, 병합·중복 제거, 프롬프트 역할·출력 형식, 청크·Top-k 값과 근거, 근거 표시 방식, 특화 기능 설계 이유, 겪은 문제와 해결
  - `docs/verification.md`: 요구사항 대조표(F2001~F2012, NF2001~NF2007 ↔ 구현 모듈 ↔ 테스트 ID), 4장 항목별 실행 결과(실측), 테스트 결과표, 셀프 체크리스트, 알려진 한계
  - 요구사항 정의서는 `docs/SPEC.md` 가 맡는다 (README에서 연결)
- 제외: 화면 스크린샷 파일(사용자가 실행해 첨부), 상호 체크리스트(사람 간 교환)
