# SPEC-018 F2015 RAG 사용 전후 품질 비교

- 상태: 완료
- 이슈: #35
- 구분: 확장 (심화 F2015, X-02)
- 대응 요구사항: F2015, PRD 4.6
- 관련 절: `docs/specs/SPEC-015-benchmark.md` §4, `docs/benchmark.md` §3

## 1. 목적
PRD 4.6이 요구하는 다음 항목을 문서로 남긴다.
- 대표 질문 5개 이상
- 같은 질문을 RAG 없이 한 번, 근거를 붙여 한 번 답한 결과를 나란히 기록
- 세 기준으로 비교: 사실 정확성, 근거 제시, 모르는 것을 모른다고 답하는지

## 2. 설계
- **데이터**: SPEC-015 QA 벤치마크 90문항을 `rag` 와 `norag` 모드로 실행한 결과 JSON을 쓴다. `norag` 는 같은 답변 모델에 근거 없이 곡·아티스트·질문만 주고, "모르면 모른다고 답하라"는 지시는 똑같이 둔다.
- **문서 생성**: `scripts/rag_comparison_report.py <결과 JSON>` → `docs/rag_comparison.md`
  - **요약 표**: 모드별 정답률(키워드/LLM)·오답률·모름 인정률·근거 제시율. 난이도(normal/hard)별 표도 함께 둔다.
  - **대표 질문 나란히 보기**: 유형마다 RAG 전후 차이가 드러나는 문항을 고른다. 최소 8개, 유형별 최소 1개.
    - 고르는 순서는 다음과 같다. 키워드·LLM 채점이 모두 일치하는 문항만 쓴다.
      1. RAG만 맞힘
      2. RAG만 모름 인정
      3. 둘 다 맞힘
    - 각 문항에는 질문, 참고 정답, 두 답변(각 300자 이내로 자름), 판정을 적는다.
  - 가사 의미(meaning) 유형은 답변에 가사 인용이 많을 수 있어 대표 질문에서 뺀다(저작권).
- **해석 절**은 사람이 확인하고 쓴다. 자동 생성 표 아래에 다음을 정리한다.
  - 사실 정확성
  - 근거 제시
  - 모름 인정
  - 그 밖의 관찰(예: RAG가 더 보수적으로 답한 meaning 유형)
