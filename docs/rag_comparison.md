# RAG 사용 전후 품질 비교 (F2015)

PRD 4.6에 따라, 같은 질문을 **RAG 없이** 한 번, **근거를 붙여(RAG)** 한 번 답하게 하고 세 기준으로 비교한다.
- 사실 정확성
- 근거 제시
- 모르는 것을 모른다고 답하는지

- 질문: SPEC-015 QA 벤치마크 90문항 (`bench/qa_cases.yaml`)
  - 일반 60: 유명곡의 크레딧·발매·타이업·배경·가사 의미, 답할 수 없는 질문 12
  - 어려움 30: 2025~2026년 곡·덜 알려진 아티스트의 편곡자·정확한 발매일·타이업
- 모델: 두 모드 모두 답변은 `gpt-6-luna`
  - RAG 없음: 곡 제목·아티스트·질문만 주고 "모르면 모른다고 답하라"고 지시한다. 지시는 RAG와 똑같다.
  - RAG: 현재 파이프라인. 근거 검색 → 근거만으로 답변, `[근거 N]` 표기
- 채점: 정답 키워드 + LLM 판정(`gpt-6-luna`) 병행(D-12). 대표 질문에는 두 채점이 일치한 문항만 쓴다.
- 실행: 2026-10-21. 표와 대표 질문은 `scripts/rag_comparison_report.py` 로 생성했다.

## 해석

### 1. 사실 정확성
- **잘 알려진 곡(일반 60)에서는 차이가 거의 없다.** RAG 없이도 정답률 0.98이다. 「Lemon」의 작곡가, 「夜に駆ける」의 원작 소설처럼 모델이 학습한 사실이기 때문이다. 대표 질문 8번이 그런 예다.
- **모델이 모르는 사실(어려움 30)에서 차이가 크다.**
  - RAG 없음: 정답률 0.07, 오답률 0.50. 이 곡에 참여하지 않은 편곡자(「山下洋介」, 2번)나 아티스트 이름(1번)을 편곡자로 답하거나, 틀린 발매일·작품(4·6번)을 단정했다.
  - RAG 사용: 키워드 기준 1.00, LLM 판정 0.93. LLM 판정이 "틀림"으로 본 2건은 「하나이 료」=花井諒처럼 표기만 다른 정답이었다.
- **전체 오답률은 0.21 → 0.04** 로 줄었다.

### 2. 근거 제시
- RAG 답변의 93%가 `[근거 N]` 을 달았다. 근거가 없는 나머지는 대부분 "제공된 문서에서 확인되지 않습니다"라는 답이다.
- RAG 없는 답변은 출처를 댈 수 없다(0%). 맞는 답이라도 사용자가 확인할 방법이 없다.

### 3. 모르는 것을 모른다고 답하는지
- 답할 수 없는 질문 12개(녹음 마이크·현 게이지·MV 예산 등)에서 RAG 사용은 **12개 모두** 모른다고 답했다(1.00).
- RAG 없음은 0.67로, **4개를 지어냈다**. 예: 「Lemon」 녹음 마이크를 「NEUMANN U 87 Ai」라고 단정했다(7번).
- 반대 방향의 실패도 있었다. RAG 없음은 2026년 곡 「咲き誇れ」를 "그런 곡이 없다"고 했다(3·5번). 모르는 것을 모른다고 한 점은 낫다. 하지만 학습 시점 이후의 사실을 다룰 수 없다는 한계가 그대로 드러난다.

### 4. 그 밖의 관찰
- **가사 의미(meaning) 유형에서는 RAG가 더 보수적이다.** RAG 0.70 / RAG 없음 0.90. RAG는 근거 문서에 없는 해석을 피하고 "문서에서 확인되지 않는다"는 단서를 단다. 정확성과 친절함 사이의 절충이 필요한 부분이다. 대표 질문에서는 가사 인용이 많아 이 유형을 뺐다.
- **응답 시간**: RAG 6.4초, RAG 없음 13.1초. 이번 측정에서는 RAG가 오히려 빨랐다. RAG 없음은 긴 설명을 생성하는 경향이 있었다.
- **채점 한계**: LLM 판정은 같은 답변에도 흔들릴 수 있다(`docs/benchmark.md` §4). 그래서 키워드 채점과 함께 보고, 대표 질문은 두 채점이 일치한 문항만 골랐다.

## 결론
- RAG의 효과는 "모델이 이미 아는 질문"에서는 작다. 반면 **모델이 모르는 최신·세부 사실과 답이 없는 질문**에서는 결정적이다.
  - 지어낸 답을 크게 줄였다. 어려운 문항 오답률은 0.50 → 0.07(LLM 판정 기준이다. 이 중 2건은 표기만 다른 정답이라 키워드 기준으로는 0.00), 답할 수 없는 질문에서 지어낸 답은 4 → 0이다.
  - 모든 주장에 출처를 붙인다.
- 이 서비스의 대상(가사·크레딧·타이업처럼 틀리면 안 되는 사실, 계속 나오는 신곡)에서는 RAG가 필수다.
